The `includes/core/` tree is layered around three concentric concerns:
- Bootstrap & shared base (`simple-stack.php`, `class-sstk-base.php`, `functions*.php`) registers global hooks, roles, menus, React assets, and loads the other layers.
- Domain models live in sibling sub-trees: `post_type_models` (apps/servers/logs), `cloud_providers` (server provisioning contracts + DO/Vultr/UpCloud/custom), `app_types` (WordPress/basic-server/stable-diffusion/vpn engines implementing the app contract), `custom_table_dns` (DNS provider/zone/record models).
- The `rest_api` layer under `api/` exposes a Simple Stack-specific `/simple-stack/v1/` surface over those models for the React admin dashboard.
Cross-child wiring happens through shared PHP classes rather than direct file includes: children depend on `SSTK_Base` / `Simple_Stack` bootstrap, on the cloud-provider abstract API for server lifecycle, on the app-type abstract API for site lifecycle, and on the post-type model classes for persistence; the REST controllers consume all of these without owning domain logic. Scripts under `apps/*/scripts/{v1,v2}/` are data-only artifacts consumed by the engine at runtime, not PHP code.
