- Every file guards against direct access with `if ( ! defined( 'ABSPATH' ) ) { exit; }` at the top of the file.
- Global helper functions are namespaced with a `sstk_` prefix rather than wrapped in a class or namespace.
- Option values are read through `sstk_get_option` (Meta Box settings) or `sstk_get_early_option` (raw `wp_options` fallback when Meta Box isn't loaded yet), never accessed directly.
- User-supplied data is validated and escaped via `sanitize_key`, `wp_unslash`, `absint`, `esc_html`, `esc_url`, and `wp_verify_nonce` before use.
- Extensibility points are exposed as `apply_filters` / `do_action` hooks (e.g. `sstk_get_cloud_providers`, `sstk_os_list`, `sstk_webserver_list`, `sstk_log_error`, `sstk_log_notification`) rather than hard-coded lists.
- Lazy-loading of sub-components uses a `classes` array keyed by identifier and guarded by `empty( SSTK()->classes[ $key ] )` before instantiation.
