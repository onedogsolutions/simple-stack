Bash scripts for Ubuntu 24.04/26.04 with OpenLiteSpeed and LSPHP 8.3, 8.4 and 8.5; OpenLiteSpeed vhosts under `/usr/local/lsws/conf/vhosts`; WP-CLI for site management; Certbot for TLS; and active integrations for Redis, Memcached, Fail2ban, Monit, Netdata, SolidWP Security, 7G, backups and site synchronization. Runtime state and callback files use `/etc/simple-stack/`.
