The module is layered around `class-wordpress-app.php` (`SSTK_WORDPRESS_APP`) which composes behavior via the trait files under `traits/traits-for-class-wordpress-app/` (admin columns, backup, commands-and-logs, multi-tenant, push-commands, script-handlers, tabs-security, upgrade). Child layers plug in through this class:
- `rest-api/` registers `/simple-stack/v1/*` endpoints whose controllers delegate to the tab/action engine.
- `tabs/` and `tabs-server/` define per-site/per-server admin panels; each tab file dispatches AJAX actions that invoke SSH command execution.
- `public/` provides WP_List_Table subclasses and shortcodes for the front-end listing/edit views.
- `assets_and_templates/` supplies CSS/JS and PHP templates rendered by the above layers.
- `scripts/v2/` is the only provisioning/management shell-script library consumed by the `script-handlers` trait. It targets Ubuntu 24.04/26.04 with OpenLiteSpeed-only hardening; there is no `scripts/v1/` tree, fallback or per-server version selector.
The REST layer and the admin-tab/AJAX layer both ultimately call into the same script-handling pipeline, so adding a new operation means updating the corresponding wrapper and raw `.txt` script under `scripts/v2/` and wiring the tab or REST controller accordingly.
