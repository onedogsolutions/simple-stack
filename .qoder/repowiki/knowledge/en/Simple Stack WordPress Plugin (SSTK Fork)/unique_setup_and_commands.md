Composer scripts: `composer lint` runs bin/lint-php.sh, `composer lint:sh` runs bin/lint-sh.sh, `composer guard` enforces the sstk_ prefix, `composer test` invokes PHPUnit. NPM scripts: `npm run dev` starts Vite, `npm run build` compiles the React dashboard to assets/dist/, `npm run verify:css` runs tools/verify-css-isolation.mjs, `npm run verify` builds then verifies CSS isolation.
