wpcd.php is the single plugin entry point: it defines shared constants (WPCD_URL/WPCD_PATH/WPCD_VERSION plus brand-color palettes), registers activation/deactivation hooks, loads Composer's autoloader via `required_files()`, then requires core classes, providers, and finally the SimpleStack REST API (`includes/core/api/class-simplestack-rest-api.php`) which mounts the `/simple-stack/v1/` namespace gated by `manage_options`. The React dashboard (admin_react_app) is built by Vite + Tailwind v4 into `assets/dist/` and enqueued from PHP; legacy jQuery screens live in static_assets alongside the new SPA. Bundled plugins (bundled_plugins) ship Meta Box add-ons and use TGMPA to auto-install the core Meta Box dependency. Tests (tests/) run against vendor-installed WordPress core via PHPUnit configured at the root, with spatie/phpunit-watcher driven by phpunit-watcher.yml. bin/ scripts wrap lint-php.sh, lint-sh.sh, and a guard enforcing the `wpcd_` prefix across PHP files; tools/verify-css-isolation.mjs validates CSS scoping for the React build.
