The module is the public-facing counterpart of the WordPress App app. `class-wordpress-app-public.php` is the singleton entry point: in its constructor it branches on `is_admin()` vs `DOING_AJAX`, registers `wp_enqueue_scripts`, `the_content`/`the_title` filters, shortcodes (`wpcd_cloud_servers`, `wpcd_cloud_server_apps`, `wpcd_deploy_server`), a single `wp_ajax_wpcd_public_wordpress-app` dispatcher, and an RW Meta Box class-name filter that swaps admin metaboxes for their public variants. It owns page-ID helpers (`get_*_list_page_id`) and the `is_public_page` gate used throughout.

- `class-public-list-table.php` defines `WPCD_Public_List_Table extends WP_List_Table`, shared by `class-servers-list-table.php` (for `wpcd_app_server`) and `class-server-apps-table.php` (for `wpcd-app`). Both are rendered inside `servers_shortcode()` / `server_apps_shortcode()` which wrap output in `#wpcd_public_wrapper` + `#wpcd_public_{servers|apps}_container`.
- `traits/grid_table.php`, `traits/table_pagination.php`, and `traits/meta-box-public.php` provide reusable grid/pagination/metabox behavior consumed by the list-table classes and the public RW Meta Box override in `rw-meta-box-public.php`.
- `custom-table/` is a self-contained sub-layer for the optional Provider/DNS-Provider custom tables: `loader.php` extends MetaBox\CustomTable\Loader, registers `[wpcd_ct_providers]` / `[wpcd_ct_dns_providers]` shortcodes, swaps in `RW_Meta_Box_Custom_Table_Public`, and delegates view/edit rendering to `views/list-table.php` and `views/edit.php`.

Dependency direction is one-way: this layer depends on the rest of WPCD (post-type managers, settings, RWMB) but exposes no internal APIs — consumers interact only through the registered shortcodes, AJAX action names, and `wpcd_is_public_page` filter.
