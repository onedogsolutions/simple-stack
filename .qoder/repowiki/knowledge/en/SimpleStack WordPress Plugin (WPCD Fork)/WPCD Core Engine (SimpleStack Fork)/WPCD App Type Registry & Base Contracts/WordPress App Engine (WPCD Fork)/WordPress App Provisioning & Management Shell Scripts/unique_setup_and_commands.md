Scripts are not meant to be run directly from this directory — they are downloaded onto a target server via `wget --no-check-certificate -O ##SCRIPT_NAME## ##SCRIPT_URL##` (see `install_wordpress_site.txt`), then executed as `sudo -E bash ##SCRIPT_NAME## >> ##SCRIPT_LOGS##.log.intermed 2>&1`. Environment variables documented in `raw/environment variables.txt` must be exported before invocation; many scripts also accept an interactive mode controlled by `$interactive=no`.
