Flat asset bundle split into two subdirectories: `css/` holds presentation styles (admin app list badges, GIT/multi-tenant sections, spinner overlay) and `js/` holds jQuery-driven client logic. JS files are scoped by runtime context — admin-only (`wpcd-wpapp-admin-app.js`, `wpcd-wpapp-server-admin.js`, `wpcd-wpapp-admin-post-type-wpcd-app.js`), shared admin helpers (`wpcd-admin-common.js`, `wpcd-wpapp-admin-common.js`), public/frontend (`wpcd-wpapp-frontend.js`, `wpcd-wpapp-public-common.js`), and a charting helper (`wpcd-wpapp-server-chart.js`). Each script is an IIFE receiving `$` and a data object (`params`, `attributes`) injected by PHP at enqueue time; AJAX calls go through `ajaxurl` in admin and `wp.ajax` on the frontend. The spinner lock/unlock pattern (`$.fn.lock` / `$.fn.unlock`) is defined once in `wpcd-wpapp-frontend.js` and reused across other scripts. CSS uses WPCD design tokens via CSS custom properties (`--wpcd-positive-color`, `--wpcd-white-color`, `--wpcd-primary-brand-color`) for consistent theming.
