The module is a leaf public layer that hooks into the WordPress front end via `WPCD_WORDPRESS_APP_PUBLIC` (class-wordpress-app-public.php), which registers shortcodes (`wpcd_cloud_servers`, `wpcd_cloud_server_apps`, `wpcd_deploy_server`), content/title filters, script/style enqueues, and a single `wp_ajax_wpcd_public_wordpress-app` endpoint. It renders two main list-table screens — servers and apps — through a shared base class hierarchy: `WPCD_Public_List_Table` extends `WP_List_Table` and composes traits `wpcd_grid_table` and `table_pagination` to produce a CSS-grid responsive layout; concrete subclasses `Servers_List_Table` and `WPCD_Server_Apps_List_Table` only override post type, columns, row actions, and no-items text. A separate optional subsystem under `custom-table/` integrates with MetaBox's Custom Table feature: `mb_custom_table_load()` lazily loads `custom-table/loader.php`, which defines `WPCD_CT_Public_Loader` extending `MetaBox\CustomTable\Loader` and exposes `wpcd_ct_providers` / `wpcd_ct_dns_providers` shortcodes plus a public metabox class `RW_Meta_Box_Custom_Table_Public`. The entry point swaps the default RWMB class name to `RW_Meta_Box_Public` (in `rw-meta-box-public.php`, using trait `meta-box-public.php`) when rendering server/app edit pages on the front end. Dependency direction is one-way: this module depends on the parent app classes (`WPCD_POSTS_APP`, `WPCD_POSTS_APP_SERVER`, `WPCD_WORDPRESS_APP`, `WPCD_MB_Custom_Table`) but they do not depend back on it.
