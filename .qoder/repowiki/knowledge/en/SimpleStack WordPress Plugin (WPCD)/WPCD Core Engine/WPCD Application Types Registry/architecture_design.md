Two layers sit under `includes/core/apps/`: the base layer (`class-wpcd-app.php`, `class-wpcd-ssh.php`, `class-wpcd-app-settings.php`) provides the abstract `WPCD_App` contract — script registry, command lifecycle, REST callback dispatch, and SSH/SFTP transport — that every concrete app extends; the concrete layer is one directory per app (`wordpress-app/`, `vpn/`, `stable-diffusion/`, `basic-server/`) each registering itself with the core's app registry so the engine can discover, instantiate, and drive them uniformly. WordPress additionally contributes a full add-on surface (admin tabs, REST controllers, public tables, traits) layered on top of the same base, while VPN/Stable Diffusion/basic-server contribute only their provisioning scripts and templates consumed by the shared engine.
