Assets are organized by type under `assets/{css,js,fonts,images}` with a build output directory `assets/dist` (currently empty). Each major admin or front-end screen has its own paired JS/CSS file following a `wpcd-<screen>.js` / `wpcd-<screen>.css` naming convention (e.g. `wpcd-admin-settings`, `wpcd-setup-wizard`, `wpcd-user-notifications-front`). Third-party libraries (Bootstrap, Select2, Magnific Popup, Chart.js) are vendored directly as minified files in `css/` and `js/`. JavaScript is written as self-contained jQuery scripts that bootstrap on `$(document).ready()` and communicate with PHP through `$.ajax` calls to either the global `ajaxurl` endpoint or the localized `WPCD_Wizard.ajax_url` object; server responses are typically handled by alerting `data.data.msg` and reloading the page. No module system or bundler is used — each script is enqueued independently by the parent plugin.
