The module is a self-contained React SPA mounted into a `#simplestack-admin` container by `index.jsx`, which seeds the initial hash route from PHP's `data-route` attribute so wp-admin owns the URL bar while the app tracks state in `window.location.hash`. `App.jsx` holds an internal route table (`/servers`, `/sites`, `/settings/providers`, `/activity`) matched via the custom `lib/router.js` (hash-only router with `:param` support) — no external routing library. Routes live under `routes/` as page components; shared chrome (`AppShell`), layout primitives (`Button`, `Card`, `Modal`, `Toast`, `DataTable`, `LogDrawer`, `SecretField`, `TabRenderer`) live under `components/`; data access is centralized in `lib/api.js`, which wraps `fetch` against `restRoot()` (`/wp-json/simple-stack/v1/`), attaches the nonce from `window.simplestackAdmin`, unwraps the `{ ok, data }` envelope, and exposes namespaced clients (`api.servers`, `api.sites`, `api.tabs`, `api.logs`, `api.providers`). `lib/schema.js` translates Meta Box field arrays returned by the server/site tabs endpoint into renderable descriptors for the generic `TabRenderer`, preserving parity with the legacy jQuery client. Styling uses Tailwind utility classes declared in `styles/index.css`. Dependency direction is strictly one-way: routes → components → lib; components never call the REST layer directly except through `api`.
