The root `wpcd.php` is the sole WordPress plugin entry point. It defines shared constants (`WPCD_URL`, `WPCD_PATH`, `WPCD_VERSION`, brand colors, script versioning) and orchestrates loading order: first Meta Box/TGMPA required plugins, then core classes (base, post types, cloud-provider registry, DNS tables), then the SimpleStack REST API layer (`includes/core/api/class-simplestack-rest-api.php`), and finally the main `WP_CLOUD_DEPLOY` class plus setup wizard. The REST layer exposes the `simple-stack/v1` namespace consumed by the React admin app; static jQuery/PHP assets live alongside it and communicate via `wp_ajax`. Composer manages PHP deps (`phpseclib`) and dev tooling (PHPCS, PHPUnit); Vite + Tailwind builds the React dashboard into `assets/dist/` and runs `tools/verify-css-isolation.mjs` to enforce CSS scoping. Tests in `tests/` target the same REST controllers and use `wp-tests-config.php` for the WP test suite bootstrap.
